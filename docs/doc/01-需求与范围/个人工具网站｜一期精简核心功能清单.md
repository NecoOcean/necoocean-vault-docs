## 一、整体定位（极简总结）

个人工具作品展示 \+ 单工具专题页 \+ 公开留言BUG反馈 \+ 后台内容管理，轻量化、无登录用户体系，**严格前后端分离：Vue 3 前端独立项目（页面与交互） \+ Spring Boot 后端服务（仅 JSON API） \+ MySQL 数据库**。

> **架构口径（v1.5 起）**：后端**不得**使用服务端渲染、模板渲染或输出任何 HTML 页面；前端与 API 经**同源部署**（同一域名，前端 `/`、API `/api/v1/`），因此**不启用 CORS**。架构细则、目录结构与部署方式见《前后端分离架构说明》。

两项已确认的设计边界：

- **「托管」严格限定为文件存储与下载**。不含在线预览、在线编辑、格式转码与在线运行（详见 ADR-001）；
- **留言联系方式为选填邮箱，仅管理员可见**。不构成用户体系，一期不发送任何邮件（详见 ADR-002）。

文件存储与分发方案（已确认）：**腾讯云 COS 对象存储 \+ 预签名直链**。下载流量不占服务器带宽；**一期不接入 CDN**（正式公开前再接入，届时不改业务代码，见 PRD 4.3）。

## 二、前台核心功能（必须上线）

### 1\. 首页

- 个人简介、网站说明展示

- **全量工具卡片列表**：图标、名称、简介、更新时间、标签

    > 一期不单独设立"全部工具列表页"——当前工具数量少，首页即承载全量列表与筛选（已确认）。导航栏"全部工具"跳转至首页工具区。

- 工具分类筛选（APP应用 / Python脚本 / 桌面工具 / 其他工具）

- 关键词搜索工具

### 2\. 工具专题详情页（核心）

每个工具独立页面、独立链接、可单独分享

- 工具详情：介绍、使用教程、版本、适配平台

- 更新日志展示

- **文件下载区**：支持 APK / PY / ZIP / 压缩包等多文件下载

    - 列表显示：文件名、文件大小、上传时间、适用平台、版本号、SHA-256 校验值

    - 允许的类型：`.apk` `.exe` `.msi` `.dmg` `.zip` `.7z` `.rar` `.py` `.tar.gz` `.pdf` `.txt` `.md` `.json` `.yaml` `.ini` `.cfg`

    - 拒绝的类型：`.html` `.htm` `.svg` `.js` `.php` `.jsp` `.asp` `.sh` `.bat` `.cmd`

    - 单文件大小上限：200 MB（已确认）

    - 外链型资源（代码仓库、Web 工具）以**站外链接**形式呈现，不在站内嵌入运行

    - 下载统一经 `/download/{file_id}` 校验后 302 跳转至带时效的 CDN 签名地址；对象存储桶私有读写，不暴露真实路径

    - **不做**文件预览、在线编辑、转码、在线运行

- 留言反馈区（无需登录即可留言）

- 管理员公开回复展示

### 3\. 留言系统（用户端）

- 匿名/自定义昵称留言

- **邮箱（选填，仅管理员可见）**，字段说明文案：`仅管理员可见，用于向你反馈问题处理结果，不会公开显示。`

- **留言分类**（必选）：使用体验 / 功能建议 / BUG报错 / 问题咨询

- **BUG 类留言附加字段**：运行平台／系统版本、所使用工具版本、复现步骤

- 留言内容、时间展示、分页（每页默认 20 条、上限 100 条；默认按时间倒序，管理员置顶优先）

- 每条留言归属对应工具页面

- 基础防刷屏（按 IP 哈希限流：**60 秒内最多 5 条**）、关键词**标记**（不拦截——命中打 `keyword_flagged` 标记进入后台待复核队列，见 PRD 4.2 / 9.3）

- **已知限制**：一期无回复通知，用户需自行回访查看

### 4\. 关于我页面

- 个人开发经历、作品汇总、联系方式、网站说明

### 5\. 全站通用

- PC \+ 手机端自适应

- 顶部导航（首页 / 全部工具 / 关于我）、底部版权信息

- 隐私政策页（含邮箱收集说明与免责声明）

## 三、后台核心功能（必须上线）

### 1\. 工具管理

- 新增工具：名称、封面、分类、介绍、教程、日志、上传文件

- 编辑工具所有内容

- 下架 / 删除工具（删除时级联清理日志、文件记录与留言，并同步删除对象存储中的对象、刷新 CDN 缓存）

- **文件上传、多版本文件管理**：类型白名单校验、单文件大小上限 200 MB、前端直传对象存储（后端签发预签名凭证，有效期 60 分钟）、随机键名存储（不使用原始文件名参与路径）、对比数据库清理无记录的残留对象；删除时同步删除对象并刷新 CDN 缓存。SHA-256 采用**方案 A**（已确认）：前端计算回传、后端仅格式校验（64 位小写十六进制）后落库；管理员上传重要文件后应自行下载核对一次

- 外链型资源的仓库地址 / Web 地址维护

- **工具分类管理**：分类增删改、排序；一期预置 4 类（APP应用 / Python脚本 / 桌面工具 / 其他工具），可继续自定义；分类名唯一，"其他工具"为兜底分类不可删除（已确认）

- **存储占用查看**：按工具统计对象存储用量与文件数，含"数据库有记录但对象缺失"的异常文件标记

### 2\. 留言管理

- 查看所有工具的全部留言；支持按工具、时间、分类、状态、**是否留有邮箱**筛选

- 留言回复、删除（删除时同步删除该条邮箱字段与其下所有回复）、**置顶**（置顶留言前台优先展示，多个置顶按时间倒序）

- **留言详情展示邮箱**（仅详情页，列表页不展示），可一键复制或直接发起邮件

- 留言状态标记：未处理 / 已处理 / 已跟进 / 无需处理（与审核状态相互独立，见 PRD 8.5）

- **反馈统计计数**：各工具留言数 / BUG 数 / 建议数（仅计数，可视化面板属二期）

- **关键词待复核队列**：命中关键词的留言在后台优先展示，由管理员复核决定保留或删除（一期口径：不拦截、即时公开，见 PRD 9.3）

- **审核接口预留**：审核通过/驳回接口一期实现（无待审数据），为终态"先审后发"预留（见 PRD 9.3 / A-14）

### 3\. 网站基础设置

- 后台账号密码修改、连续登录失败锁定（**5 次失败锁定 15 分钟**，锁定期内正确密码也拒绝，期满自动恢复）

- 首页简介、站点信息配置（网站标题、版权、ICP 备案号、首页公告、"关于我"与隐私政策内容编辑）

- 留言功能开关

- **审核模式预留**：内部以配置项 `message_audit_mode`（post / pre）存放，一期固定 post（先发后审）且后台不暴露切换入口，供二期切换先审后发使用（见 PRD 2.2.3、9.3）

## 四、一期明确不做（缩减成本、快速上线）

- 不做用户注册、登录、会员体系

- 不做点赞、收藏、评分

- 不做复杂数据统计、可视化面板

- 不做留言图片上传（二期再加，一期保留字段位不实现）

- 不做付费、广告，以及**复杂评论审核流程**——注意口径：一期为"先发后审 \+ 关键词标记"（命中关键词仅打标记不拦截，后台待复核）；审核相关的**数据字段（audit_status 等）与后台审核接口一期即建**，为终态"先审后发"预留、避免二期改表返工（见 PRD 9.3）

- **不做文件在线预览**（含 PDF/图片/文本预览、压缩包目录浏览）

- **不做在线编辑、格式转码、在线运行**（含 Web 工具站内嵌入、Python 脚本在线执行、代码仓库托管）

- **不做文件分享链接、权限分级、版本比对、断点续传**

- **不做任何邮件发送**（验证邮件、回复通知、订阅）——这也是留言邮箱字段不构成骚扰入口的前提

- **不做访客对留言的二次回复**（评论线程化；一期回复方仅限管理员）

## 五、最终交付能力（一期跑完即可用）

你可以无限发布新工具 → 每个工具自动生成独立专题页 → 用户可看介绍、下文件、留BUG/建议 → 你后台统一处理反馈、更新版本。完全满足个人工具站长期使用。
